# Rock Paper Scissors

A standard Rock Paper Scissors game, fully randomized against the computer.

## How to run the project:
To run this project locally, you will need an Integrated Development Environment (IDE) and a C++ compiler. 
Recommended Setup: [Code::Blocks](https://codeblocks.org) bundled with the MinGW compiler (https://sourceforge.net/projects/mingw/). 
Alternative: Any standard C++ compiler (like GCC/Clang) via the terminal.

## Quick play:
Paste game.cpp into an online debugger capable of compiling your file. Recommended: https://www.onlinegdb.com. Make sure you set the lanugage to C++.

## How to play:
For PAPER, type p; for SCISSORS, type s; for ROCK, type r.
For a new round, restart the program, to ensure the randomisation of the computer's choices.

Have fun!
